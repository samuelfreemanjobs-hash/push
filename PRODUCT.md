# DiskLordz — product context (Impeccable)

## Register

Premium **synthesis-only** drum tools for trap, Baton Rouge, NOLA bounce, and Memphis phonk producers. Primary DAW: **FL Studio** (Windows first).

## Users

- Bedroom beatmakers posting type beats (YouTube, BeatStars)
- Southern / bounce producers who want **raw WAVs + VST** in one checkout
- Buyers who reject iLok, bloated romplers, and generic “AI kit” visuals

## Product purpose

1. **Detroit Phonk Trap Maker** (not “TrapDrumEngine”) — low-latency drum VST with BR 808 glide, 2× soft clip, **drag WAV/MIDI to FL Playlist on Core+**
2. **Louisiana / Forge kits** — 24-bit WAV packs from `drum-forge-v4` factory
3. **Lite lead magnet** — free VST3 + small WAV set → Core ($39–49) → Suite ($79–89)

## Brand personality

- **Hardware booth** — rubber pads, brushed gunmetal, amber backlit accents
- **Confident, not corporate** — producer-to-producer tone; no startup SaaS vibes
- **Grit + clarity** — dark UI, high contrast labels, obvious primary actions

## Anti-references

- Purple/blue AI gradients, glassmorphism cards, Inter-only marketing pages
- Generic “ultimate beat production suite” stock copy
- Cluttered plugin UIs with 20 tiny knobs before pad workflow

## Design principles

1. **Pads first** — largest touch targets; macros secondary (Glide, 808 Clip)
2. **Drag is the demo** — show “drop to FL Playlist” in hero and faceplate
3. **Three tiers, one story** — Lite / Core / Suite; match `disklordz-ralph/vst/LICENSING.md`
4. **Mobile-readable storefront** — producers browse on phone between sessions

## Accessibility & inclusion

- Body text ≥ 4.5:1 contrast on `#121216` backgrounds
- Focus rings on pads and CTAs; no color-only state
- Reduce motion: respect `prefers-reduced-motion` on storefront animations
