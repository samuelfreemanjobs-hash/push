MPC SAMPLE FORGE - QUICK START
==============================

WHAT'S IN THIS FOLDER
  MPC Sample Forge (.exe / .app)   the app
  mpcforge (.exe)                  command-line tool for automation
  Examples/                        an example custom style (JSON)
  Demo-Samples/                    samples this exact build rendered during its self-test


FIRST RUN

  Windows
    Double-click "MPC Sample Forge.exe".
    If SmartScreen says "Windows protected your PC": click "More info", then "Run anyway".
    (The app isn't code-signed yet.)

  macOS
    Right-click "MPC Sample Forge.app" and choose Open, then click Open again.
    If macOS says the app "is damaged" or "can't be opened":
      System Settings > Privacy & Security > scroll down > "Open Anyway",
      or run this in Terminal:  xattr -dr com.apple.quarantine "/path/to/MPC Sample Forge.app"
    The app runs on both Apple Silicon and Intel Macs.

  Linux
    ./"MPC Sample Forge"


MAKE YOUR FIRST KIT (about a minute)
  1. Instrument: leave "Built-in Synth", or pick one of your VST3s and click "Edit Sound".
  2. Style: pick a recipe, e.g. "Jet Life EP Bell" or "Memphis / OG Phonk Kit".
  3. 16 Levels root: "Recipe's own root". Tick "16-pad banks".
  4. Click Generate. The output folder opens when it's done (default: Music/MPC Sample Forge).
  5. Copy the folder to your MPC. _MPC_Setup.txt explains the pad settings.


SOMETHING WRONG?
  Click "Diagnostics" (top right) > "Run Self-Test" > "Copy Report", and send the report.
  Load your VST3 first so the self-test checks it too.

  Command line:   mpcforge --diagnose
                  mpcforge --diagnose --plugin "C:\Program Files\Common Files\VST3\YourSynth.vst3"

  Log file:
    Windows   %APPDATA%\MPCSampleForge\Logs\forge.log
    macOS     ~/Library/MPCSampleForge/Logs/forge.log
    Linux     ~/.config/MPCSampleForge/Logs/forge.log
  The log includes a stack trace if the app crashes (e.g. a plugin crashes it).
