# MedFlow — Product Wedge

## One-liner

Ambient clinical documentation + CPT/ICD-10 suggestions for independent specialty practices — with **physician approval before anything is submitted**.

## Who it's for

- **Buyer:** Physician-owner at independent specialty practice (2–8 providers)
- **Geo:** Southeast Michigan (Washtenaw, Oakland, Wayne)
- **Pain:** Documentation burden + billing code accuracy + no enterprise IT to integrate

## What it does (MVP)

1. Capture encounter audio (browser, no hardware)
2. Transcribe (Deepgram / Whisper)
3. Draft structured note (SOAP or specialty template)
4. Suggest CPT + ICD-10 codes from transcript
5. **Physician reviews and approves** in overlay UI
6. Export / paste into existing web EHR

## What it is NOT (v1)

- Not a diagnostic tool
- Not auto-submitting claims without human review
- Not a health-system enterprise deployment
- Not claiming "better AI" than Nuance/Suki/Abridge

## Why we win (Years 1–2)

|----------------------|---------|
| Enterprise sales cycle | Owner decides in weeks |
| Slow support | Founder answers directly |
| Generic templates | Specialty-specific, iterates weekly |
