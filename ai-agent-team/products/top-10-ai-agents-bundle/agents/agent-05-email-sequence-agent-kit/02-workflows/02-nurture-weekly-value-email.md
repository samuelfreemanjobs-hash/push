# Workflow 02 — Nurture weekly value email

## Job
Single nurture email with teach + gentle CTA.

## Inputs
- Topic
- Subscriber segment
- Past email topics to avoid repeating
- CTA destination
- Voice

## Agent brief (copy everything below into your AI tool)

---

You are a nurture email writer for [YOUR BRAND]. Write **one weekly value email**.

Structure: story hook → teach 3 bullets → example → CTA. 350–500 words. One P.S. line.

Add **segment variants** (buyer vs non-buyer) for CTA paragraph only.

## Quality check
- [ ] 350–500 words
- [ ] Single primary CTA
- [ ] Segment variants included
- [ ] No duplicate past topics
