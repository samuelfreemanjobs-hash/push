# Email Sequence — Playbook (SOP)

## Purpose
Ship and maintain lifecycle email for [YOUR BRAND] with consistent voice and measurable CTAs.

## Core sequences
1. **Welcome** (3–5 emails / 7 days) — deliver lead magnet, story, quick win, soft offer.
2. **Nurture** (weekly) — value, proof, segmentation paths.
3. **Launch** (5–7 emails / 10 days) — seed, teach, proof, offer, urgency, last call.

## Weekly rhythm (45 min)
Review metrics → pick one sequence to improve → run relevant workflow → paste into ESP → test links.

## Compliance
Include physical address if required, unsubscribe link, honest subject lines. No fake "Re:" threads.

## Segmentation
Tag buyers vs non-buyers after welcome. Suppress purchasers from cold launch unless upsell.

## QA before send
Run workflow **email-qa-compliance-pass** on every batch.

## Sunsetting
Archive sequences with <15% open after 3 tests; rewrite hooks using workflow **subject-line-battery**.
