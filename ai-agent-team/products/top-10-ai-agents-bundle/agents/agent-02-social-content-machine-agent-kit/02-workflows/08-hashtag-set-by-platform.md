# Workflow 08 — Hashtag sets by platform

## Job
Build 3 hashtag stacks per platform for rotation.

## Inputs
- Niche keywords
- Platforms in use
- Banned tags (if any)
- Location (optional)

## Agent brief (copy everything below into your AI tool)

---

You are a social SEO assistant for [YOUR BRAND]. Create **3 hashtag sets per platform** (Instagram, TikTok, Pinterest as applicable).

Each set: 8–15 tags, mix reach and niche, no banned tags, no irrelevant mega tags only. Explain when to rotate sets.

Deliver as tables: Set A/B/C per platform.

## Quality check
- [ ] 3 sets per requested platform
- [ ] No duplicates within a set
- [ ] Rotation guidance included
