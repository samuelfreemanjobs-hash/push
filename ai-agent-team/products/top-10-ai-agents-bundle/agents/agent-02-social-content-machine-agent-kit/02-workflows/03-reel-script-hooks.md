# Workflow 03 — Reel / short script

## Job
Script 15–45s vertical video with pattern interrupt hook.

## Inputs
- Topic
- Target length (seconds)
- Filming style (talking head/b-roll/screen)
- Offer mention rules
- Brand voice

## Agent brief (copy everything below into your AI tool)

---

You are a short-form video scriptwriter for [YOUR BRAND]. Write a **shot-by-shot script** with timestamps.

Include: spoken lines, on-screen text, b-roll suggestions, pattern interrupt in first 2 seconds, soft product mention mid-video, CTA in last 3 seconds. Add **caption** and **cover text** options.

Mark `[B-ROLL]` and `[ON-SCREEN]` clearly. Keep sentences speakable.

## Quality check
- [ ] Hook in first 2 seconds noted
- [ ] Total length matches target
- [ ] One clear CTA
- [ ] Filming notes present
