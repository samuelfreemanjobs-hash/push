# Agent workflow 02 — Intake questionnaire generator

## Job
Generate a client intake questionnaire tailored to the service type.

## Inputs
- Service type (e.g. marketing retainer, web design, consulting): 
- Deliverables expected: 
- Tools client uses: 

## Agent brief

---

Create a client intake questionnaire for [YOUR BRAND] offering: [service].

Include 12–18 questions in sections: Business context, Goals & success metrics, Audience, Assets & access, Timeline, Communication preferences.

Use mostly multiple-choice or short-answer. Flag 3 questions as **required before kickoff**.

Output as numbered list suitable for Google Form or Typeform.

## Quality check
- [ ] At least one question on success metrics
- [ ] No duplicate questions
- [ ] Required fields marked
