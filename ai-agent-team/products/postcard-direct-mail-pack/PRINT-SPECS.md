# Postcard print specifications

| Item | Value |
|------|--------|
| Standard size | 4" × 6" (101.6 × 152.4 mm) |
| Bleed | Add 0.125" (3 mm) per side if printing professionally |
| Safe zone | Keep text 0.25" inside trim |
| Resolution | 300 DPI for photos |
| Color | CMYK for offset; RGB OK for many online printers |

**Files in this pack**

- `templates/4x6-postcard-front.html` — open in browser → Print to PDF
- `templates/4x6-postcard-back.html` — mailing side layout
- `postcard-copy-swipe-file.md` — headlines and body formulas
- `direct-mail-checklist.md` — campaign checklist

Replace `[YOUR BRAND]`, offer, and QR URL before printing.
