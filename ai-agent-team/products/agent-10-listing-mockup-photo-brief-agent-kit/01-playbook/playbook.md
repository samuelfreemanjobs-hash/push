# Listing Mockup & Photo Brief — Playbook (SOP)

## Purpose
Standardize how [YOUR BRAND] produces 5–10 listing images that explain the product in 2 seconds.

## Image set formula
1 Hero mockup | 2 What's included | 3 How to use | 4 Size/format proof | 5 Lifestyle or context | 6 Trust (reviews/license) | 7 FAQ visual | 8 Optional video cover.

## Per-SKU workflow (60 min)
Run 01 strategy → 02 shot list → 03 mockup brief → produce in Canva/PS → 09 thumbnail test → publish.

## Tools
Canva, Photoshop, smart mockups, or AI backgrounds—briefs specify.

## Consistency
Use brand kit colors/fonts from workflow 05 each quarter.

## Mobile first
Thumbnail readable at 300px width—workflow 09 required.
