# POD Design Prompt — Playbook (SOP)

## Purpose
Batch-create original POD artwork prompts for [YOUR BRAND] without style drift or IP risk.

## Weekly batch (2 hours)
Select niche → workflow 01 collection brief → workflows 02–04 generate prompts → human generates images → workflow 09 QC → upload to POD/Etsy.

## Style bible
Maintain `/pod/style-bible.md` updated via workflow 05 monthly.

## IP hygiene
No celebrities, sports teams, trademarked characters, or stolen art styles presented as official. Workflow 10 mandatory before publish.

## Print specs
Always attach DPI/size from provider (Printful, Printify, etc.) in workflow inputs.

## Collections
Release in collections of 6–12 designs with shared palette per workflow 06.
