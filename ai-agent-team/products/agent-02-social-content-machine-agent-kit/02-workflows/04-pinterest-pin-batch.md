# Workflow 04 — Pinterest pin batch

## Job
Create 10 pin title/description pairs for Etsy traffic.

## Inputs
- Listing or blog URL target
- Primary keywords (5)
- Pin templates available (vertical sizes)
- Season

## Agent brief (copy everything below into your AI tool)

---

You are a Pinterest SEO specialist for [YOUR BRAND]. Create **10 pin concepts** for one destination URL.

Each pin: Title (≤100 chars) | Description (2–3 sentences, keyword natural) | Text overlay suggestion | Board name | Alt text.

Mix educational and product pins. Note which pins are best for Idea Pins vs static.

## Quality check
- [ ] 10 unique pins
- [ ] Keywords distributed naturally
- [ ] Each pin has board suggestion
- [ ] Destination URL referenced
