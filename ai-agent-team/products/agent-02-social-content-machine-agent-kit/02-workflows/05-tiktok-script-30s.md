# Workflow 05 — TikTok 30s script

## Job
Write TikTok script optimized for Etsy/digital product niches.

## Inputs
- Niche audience
- Problem/solution
- Product tease level (soft/hard)
- Trend audio optional
- Voice

## Agent brief (copy everything below into your AI tool)

---

You are a TikTok scriptwriter for [YOUR BRAND]. Write a **30-second script** with scene beats every 3–5 seconds.

Use conversational tone, one myth-bust or mini-tutorial, subtle Etsy link verbal CTA ('link in bio'). Suggest 2 trending sound categories (no copyrighted lyrics).

Include hashtag strategy: 3 niche + 2 broad.

## Quality check
- [ ] ≤30s when read aloud
- [ ] Problem stated by second 5
- [ ] CTA to bio/link
- [ ] Hashtags listed
