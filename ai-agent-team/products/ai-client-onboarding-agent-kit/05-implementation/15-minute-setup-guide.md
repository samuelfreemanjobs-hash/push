# 15-minute setup guide

## Minute 0–3: Brand placeholders

Find and replace in all folders:

- `[YOUR BRAND]` → your company name
- `[YOUR NAME]` → your name
- `[BOOKING_LINK]` → Calendly or scheduling URL
- `[PORTAL_LINK]` → client portal, Notion, or shared drive
- `[SUPPORT_EMAIL]` → support inbox

## Minute 3–7: Choose your stack

Pick one path (don't do all three):

| Path | Best for | Use these files |
|------|----------|-----------------|
| **Email-first** | Freelancers, small agencies | Workflows 01–06 + `04-message-templates/emails.md` |
| **Portal-first** | Productized services | Workflows 07–09 + SOP section 4 |
| **High-touch** | Consulting retainers | All 12 workflows + kickoff call script (workflow 08) |

## Minute 7–12: First client test run

1. Open `03-tracker/client-onboarding-tracker.csv`.
2. Add a test row (use yourself as the client).
3. Run workflows **01 → 03 → 08** in your AI tool; paste outputs into drafts (don't send yet).
4. Check each draft against the **Quality check** line in the workflow file.

## Minute 12–15: Go live

- [ ] Save edited templates to your email tool or CRM
- [ ] Block 30 minutes on calendar for "new client onboarding" within 24h of every sale
- [ ] Pin `01-sop/client-onboarding-sop.md` where your team can see it

## Success metric

**Onboarding complete** = client has portal access, kickoff done, first deliverable date confirmed, and invoice schedule acknowledged — all rows in tracker marked Done.
