# Client onboarding SOP — [YOUR BRAND]

**Owner:** [YOUR NAME]  
**Last updated:** 2026  
**Applies to:** All new paying clients

---

## 1. Purpose

Deliver a consistent first 14 days so clients feel confident, informed, and ready to work with us — without heroics or missed steps.

## 2. Triggers

Start this SOP when:

- Contract is signed **or** first payment is received (whichever your offer uses)
- A project slot is confirmed on the calendar

## 3. Roles

| Role | Responsibility |
|------|----------------|
| Account owner | Owns relationship, kickoff, escalation |
| Delivery lead | Scope, timeline, first deliverable |
| Admin (optional) | Invoices, folder setup, calendar invites |

## 4. Timeline (14 days)

### Day 0 — Welcome (within 2 business hours)

- Send welcome email (see `04-message-templates/emails.md` #1)
- Create client row in tracker; status `Welcome sent`
- Create client folder: `Clients / [Client Name] / Onboarding`

### Day 0–1 — Access & assets

- Send portal / drive link and list of requested files
- Status `Awaiting client inputs`

### Day 1–3 — Kickoff

- Schedule 45–60 min kickoff (workflow 08 for agenda)
- Status `Kickoff scheduled` → `Kickoff complete`

### Day 3–7 — Plan lock

- Confirm scope, milestones, communication rhythm
- Send recap email (template #4)
- Status `Plan locked`

### Day 7–14 — First value

- Deliver first agreed artifact or checkpoint
- Status `First value delivered` → `Onboarding complete`

## 5. Required client inputs

Customize per offer; default list:

- Brand assets (logo, colors, fonts) if applicable
- Access credentials or invites (as per contract)
- Completed intake questionnaire
- Billing contact if different from primary

## 6. Communication standards

- Response time: [e.g. 1 business day]
- Channel order: email for decisions; Slack/DM for quick questions if contracted
- No scope changes without written confirmation (email reply OK)

## 7. Escalation

If client is unresponsive 5 business days after two follow-ups:

1. Send escalation email (template #6)
2. Account owner decision: pause work / extend timeline / offboard per contract

## 8. Offboarding edge case

If client cancels during onboarding: send professional close (template #7), archive folder, mark tracker `Offboarded`.

## 9. Quality checklist (internal)

Before marking **Onboarding complete**:

- [ ] Kickoff held and notes stored
- [ ] Milestones in writing with dates
- [ ] Client has one clear "next step"
- [ ] Invoice schedule confirmed
- [ ] Tracker 100% for mandatory fields
