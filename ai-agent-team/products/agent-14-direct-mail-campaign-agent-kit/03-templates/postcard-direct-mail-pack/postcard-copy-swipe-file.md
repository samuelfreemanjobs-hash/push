# Postcard copy swipe file

Use one headline + one subhead + one CTA per card.

---

## Headlines (pick one)

1. **[City] business owners:** Still losing leads after 5pm?
2. Your competitors aren't smarter — they're more **systemized**.
3. **Free [audit/checklist]** for local [industry] — postcard offer
4. We install **marketing systems** that run without you
5. **AI + ops** for small teams — without the enterprise price tag

## Subheads

- [YOUR BRAND] helps [audience] get [outcome] in [timeframe].
- Scan the code for the [lead magnet] — no call required.
- Limited to [number] redemptions this month.

## CTAs

- Scan → [short URL]
- Text **[KEYWORD]** to **[number]** (if compliant in your region)
- Call **[phone]** — mention this card

## Body (short — back or front)

Most [audience] struggle with [pain]. We deliver [deliverable] so you get [outcome].  
**[YOUR BRAND]** | [city] | [website]

## A/B test ideas

- Offer A: free audit vs Offer B: $ off first month
- Photo: founder vs product screenshot
- QR vs plain URL only
