# Direct mail campaign checklist

## Before design
- [ ] Define one offer (single CTA)
- [ ] Select list (geo, past customers, purchased leads — comply with laws)
- [ ] Set budget: print + postage + contingency 10%

## Creative
- [ ] Front: one headline, one visual, brand mark
- [ ] Back: return address, postage area clear, CTA + QR or short URL
- [ ] Proofread by someone who didn't write it

## Print & mail
- [ ] Export PDF with bleed if required
- [ ] Order print proof
- [ ] Track mail drop date
- [ ] Landing page or phone matches postcard promise

## Measurement (30 days)
- [ ] Unique URL or code for attribution
- [ ] Leads / redemptions logged in Marketing Command Center Excel
- [ ] ROI = (revenue from campaign − cost) / cost
