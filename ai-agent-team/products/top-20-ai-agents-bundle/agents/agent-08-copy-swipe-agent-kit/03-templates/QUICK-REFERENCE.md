# Copy frameworks — quick reference ([YOUR BRAND])

| Framework | Best for | Structure |
|-----------|----------|-----------|
| AIDA | Ads, landing heroes | Attention → Interest → Desire → Action |
| PAS | Email, pain-led offers | Problem → Agitate → Solve |
| BAB | Transformation stories | Before → After → Bridge |
| 4Ps | Bulky sales pages | Promise → Picture → Proof → Push |
| FAB | Product bullets | Features → Advantages → Benefits |
