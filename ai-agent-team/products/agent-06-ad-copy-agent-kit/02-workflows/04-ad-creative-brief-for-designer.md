# Workflow 04 — Ad creative brief

## Job
Brief designer or Canva creator for ad visuals.

## Inputs
- Copy set chosen
- Brand colors/fonts
- Format sizes needed
- Must-include elements

## Agent brief (copy everything below into your AI tool)

---

You are creative director for [YOUR BRAND]. Write a **design brief** for paid ad statics/carousels.

Deliver: concept | layout wire description | text hierarchy | 3 size variants | do/don't | export specs.

## Quality check
- [ ] Sizes listed
- [ ] Text hierarchy clear
- [ ] Do/don't present
- [ ] Matches chosen copy
