## 1. Windows VST3 installer & code signing

Do not ship raw `.vst3` ZIPs to customers without **installer + signing** (SmartScreen).

| SKU | Inno Setup | VST3 source |
|-----|------------|-------------|
| **Detroit Phonk Trap Maker (Lite/Core)** | `disklordz-ralph/vst/installer/DetroitPhonkTrapMaker-*.iss` | `Detroit Phonk Trap Maker.vst3` |
| **DrumSynth Autoresearch (demo/NFR)** | `disklordz-ralph/vst/installer/DrumSynth-Autoresearch.iss` | `DrumSynth Autoresearch.vst3` |

```powershell
$build = "C:\Dev\push\disklordz-ralph\vst\starter-cpp\build"
$vst = Join-Path $build "DetroitPhonkTrapMaker_artefacts\Release\VST3"
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" /DBuildRoot="$vst" `
  "disklordz-ralph\vst\installer\DetroitPhonkTrapMaker-Lite.iss"

signtool sign /fd SHA256 /tr http://timestamp.digicert.com /a `
  "Assets\Releases\installers\DetroitPhonkTrapMaker-Lite-1.0.0-win64.exe"
```

Use **EV/OV** code signing (DigiCert, Azure Trusted Signing, etc.). Sign the **outer `.exe`**; optional inner `.vst3` signing for enterprise DAW policies.

### macOS (when AU ships)

- Sign: `codesign --deep --force --options runtime`
- Install paths: `/Library/Audio/Plug-Ins/VST3/`, `/Library/Audio/Plug-Ins/Components/`
- `pkgbuild` + `xcrun notarytool` before `.dmg` — **AU is macOS-only**; Windows CMake targets exclude AU.

Details: `disklordz-ralph/vst/installer/README.md`.

## 2. 24-bit WAV kit packaging

Generated by `factory/autoresearch/export_kit.py`:

| Rule | DiskLordz default |
|------|-------------------|
| Layout | `Kicks/`, `Snares/`, `Hats/` under `outputs/packs/<PACK_NAME>/` |
| Naming | `DLZ_Kick_C1_Hard_v127.wav` (`FILE_PREFIX` in `export_kit.py`) |
| Format | 24-bit PCM, 48 kHz (env `KIT_SAMPLE_RATE`) |
| Peak | ~**-0.3 dBFS** (`TARGET_PEAK_DBFS`) |
| Legal | `ROYALTY_FREE_LICENSE.txt` + `LICENSE_EULA.txt` (added by `package_release.py`) |

Compatible with FL Studio drag-drop, Ableton, Logic, SFZ (`--sfz`).

## 3. Automated release bundle

After **pluginval 8**, **evaluate_vst.py**, optional **Strix**, and **export_kit.py**:

```powershell
cd C:\Dev\push
python disklordz-ralph\business\release\package_release.py --version 1.0.0 --include-drumsynth-vst
# or
.\scripts\package-release.ps1 -Version 1.0.0 -IncludeDrumSynth
```

Outputs: `disklordz-ralph/business/release/dist/Release_v<ver>_<date>/`

- `DiskLordz_DrumKit_v*.zip`
- Optional VST3 ZIPs
- `SHA256SUMS.txt` for R2/S3 upload verification

Env: `DLZ_BUILD_DIR`, `DLZ_RELEASE_VERSION`, `DLZ_BRAND_PREFIX`.
