### 3. ARCHITECTURE: LAYERED REALTIME SYNTHESIS

Implement **Body / Attack / Texture** as real independent synthesis layers. Each layer owns phase, envelope, filter, modulation, random generator, and voice state. Per-pad voice config is immutable while a note plays or updated via explicitly smoothed safe parameters.

**Body:** sine/triangle/phase-distorted oscillator, dual oscillator, FM operators, resonators, additive partials, metallic pulse network, synthesized noise, and modal synthesis chosen by instrument. Controls: fundamental/root, cents, envelope (A/H/D/R), pitch attack/start, pitch curve, sweep, glide, tone, dynamic response, level, phase policy.

**Attack:** synthetic click, filtered noise impulse, rapid tonal chirp, short FM strike, burst generator, selectable high-pass/band-pass; attack transient envelope, click pitch, relative delay in fractional samples, phase polarity, transient hardness, velocity.

**Texture:** filtered colored noise, inharmonic metallic network, digital/bit-reduced noise, FM bell/tick, spring/plate resonator, procedural rattle, multi-burst clap/hat tail, time-varying EQ and stereo width; independent envelope and pitch/noise controls.

**Mixer:** equal-power or amplitude mixing chosen per context; phase-aligned crossovers for 808s; gain staging with defined headroom; optional soft clip; mono-safe sub <120 Hz when appropriate; output meters; no default hard limiting that destroys transient. Separate per-layer mute/solo, locks and parameter snapshots. Maintain fixed upper bounds for realtime complexity and memory.

**For each drum class**, implement tailored modules (not universal parameters blindly applied):
- **808 Bass:** sample-accurate note tuning, clean sub, harmonics, pitch drop, glide/legato, ADSR, distortion branch, optional kick/808 transient blend, mid-band effects, note-off, anti-click envelopes.
- **Kick:** sweep and body, synthesized attack noise, dynamic click, punch resonance, controlled sub-tail.
- **Snare:** 2–6 modal tones, noise excitation, snappy filter, staggered buzz, pitch response.
- **Clap:** 3–6 independent burst envelopes, adjustable spacing, high/band-pass, optionally synthesized early reflections.
- **Closed/Open Hat:** six-or-more inharmonic oscillator network with bandlimited pulse options, noise, bright filtering, open/closed choking, articulations.
- **Rim/Tom:** dual modal bodies, impact exciter, rim/click transient; tom pitch movement.
- **FM/Metal/Bell/Perc:** 2/4/6 operator FM as configured, index envelopes, phase modulation, feedback with bounded stability, inharmonic modes.
- **Synthetic Foley/FX:** procedural impact, mechanical rattle, spring, laser, sweep, riser, reverse-envelope render, shaped noise. No external foley dependence.

**DSP shared components:** oscillators (BLEP/polyBLEP for sharp edges, sine, triangle, noise), sample-rate-correct envelopes, state-variable filters, multiple independent filter instances, transient generator, halfband oversampling (2x/4x/8x), waveshaper (soft clip, asymmetric, fold), DC blocker, gain, stereo field, delay/reverb (optional), FM/modals, glide, deterministic PRNG. Explicitly manage oversampling/filter latency, phase, transition clicks, denormals, and output bounds. Expose per-voice and global CPU meters.

### 6. HYPER DNA 2D MORPH ENGINE

Implement XY matrix with 5 DNA profiles: Plugg, Rage, Hypertrap, Hyperpop, Digicore; plus a user-adjustable *Morph Intensity* and source lock masks. Source recipe remains intact when intensity = 0. Compute normalized weights deterministically using inverse-distance weighting with a small epsilon (or selectable smooth radial basis weighting). At intensity=1, genre parameters govern the morph while retaining user locks.

Pitch/root frequencies, envelope durations, drive, oscillator ratios and glide use log-domain interpolation where positive. Wet mixes, gains, normalized brightness and noise amounts use safe linear interpolation. Discrete algorithm changes require parallel execution and latency-aligned crossfade, not an abrupt enum switch. Do **not** apply morph intensity twice to pitch start ratio. Do **not** assume two processing architectures are spectrally or phase compatible. Smooth XY changes 5–30 ms (configurable) and avoid per-sample expensive recomputation of complex geometry; update target at control rate and ramp sample accurately.

Instrument-specific invariants: preserve root tuning for 808, primary pitch/fundamental for tonal percussion, coherent noise burst structure for clap, fundamental kick thump for kick, metallic/noise identity for hats. Parameter locks: root, pitch envelope, transient, tail, modulation, stereo, texture, distortion, seed. Preset history, DNA Capture/Evolve/Export, blend snapshots, morph sequencer with per-step XY values. Ensure deterministic offline automation and audio quality.
